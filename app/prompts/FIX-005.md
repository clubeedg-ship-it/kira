# FIX-005 — Rate Limiting on Auth Endpoints

## Agent Instructions

Add rate limiting to prevent brute force attacks on login and signup spam.

**Read:** `CRITICAL-FIXES.md` Section FIX-005, `src/server/auth.ts`, `src/server/index.ts`

**What to do:**

1. **Install:** `npm install express-rate-limit`

2. **Create `src/server/middleware/rate-limit.ts`:**
```typescript
import rateLimit from 'express-rate-limit';

// Login: 10 attempts per 15 minutes per IP
export const loginLimiter = rateLimit({
  windowMs: 15 * 60 * 1000,
  max: 10,
  message: { error: { code: 'RATE_LIMITED', message: 'Too many login attempts. Try again in 15 minutes.' } },
  standardHeaders: true,
  legacyHeaders: false,
  keyGenerator: (req) => req.ip || req.headers['x-forwarded-for']?.toString() || 'unknown',
  skip: (req) => process.env.NODE_ENV === 'test',
});

// Signup: 5 per hour per IP
export const signupLimiter = rateLimit({
  windowMs: 60 * 60 * 1000,
  max: 5,
  message: { error: { code: 'RATE_LIMITED', message: 'Too many signups. Try again later.' } },
  standardHeaders: true,
  legacyHeaders: false,
  keyGenerator: (req) => req.ip || req.headers['x-forwarded-for']?.toString() || 'unknown',
});

// Global API: 200 requests per minute per user/IP
export const apiLimiter = rateLimit({
  windowMs: 60 * 1000,
  max: 200,
  message: { error: { code: 'RATE_LIMITED', message: 'Too many requests.' } },
  standardHeaders: true,
  legacyHeaders: false,
  keyGenerator: (req) => (req as any).userId || req.ip || 'unknown',
});
```

3. **Apply in `src/server/index.ts`** BEFORE the auth handler:
```typescript
import { loginLimiter, signupLimiter, apiLimiter } from './middleware/rate-limit';

// Auth rate limits (before Better-Auth handler)
app.use('/api/v1/auth/sign-in', loginLimiter);
app.use('/api/v1/auth/sign-up', signupLimiter);

// Global API rate limit (after auth middleware)
app.use('/api/v1', apiLimiter);
```

4. **Add `trust proxy`** if behind reverse proxy (Cloudflare, nginx):
```typescript
app.set('trust proxy', 1); // Trust first proxy
```

## Acceptance Test
```bash
# Brute force login
for i in $(seq 1 12); do
  curl -s -o /dev/null -w "%{http_code}" -X POST localhost:3008/api/v1/auth/sign-in/email \
    -H "Content-Type: application/json" -d '{"email":"a@b.com","password":"wrong"}'
done
# First 10 return 401 (wrong creds), 11th and 12th return 429 (rate limited)

# Signup spam
for i in $(seq 1 7); do
  curl -s -o /dev/null -w "%{http_code}" -X POST localhost:3008/api/v1/auth/sign-up/email \
    -H "Content-Type: application/json" -d "{\"email\":\"spam${i}@test.com\",\"password\":\"test1234\",\"name\":\"Spam\"}"
done
# First 5 return 200, 6th+ return 429

# Rate limit headers present
curl -I localhost:3008/api/v1/auth/sign-in/email
# X-RateLimit-Limit: 10
# X-RateLimit-Remaining: 9
```
