# FIX-009 — Cost Tracking on Failed Agent Jobs

## Agent Instructions

Fix missing cost tracking when Anthropic API calls fail after consuming tokens.

**Read:** `CRITICAL-FIXES.md` Section FIX-009, `src/server/jobs/agent-work.ts` lines 570-600

**What to do:**

1. **Find the Anthropic API call** in agent-work.ts (the `client.messages.create()` call)

2. **Restructure to capture usage before error handling:**

```typescript
let tokensUsed = 0;
let costUsd = 0;
let apiResponse: Anthropic.Message | null = null;

try {
  apiResponse = await client.messages.create({
    model: resolvedModel,
    system: params.systemPrompt,
    max_tokens: DEFAULT_MAX_TOKENS,
    messages: [{ role: 'user', content: params.userPrompt }],
  });

  // Extract usage immediately — before any processing that might fail
  const usage = apiResponse.usage;
  tokensUsed = (usage?.input_tokens ?? 0) + (usage?.output_tokens ?? 0);
  costUsd = calculateCost(resolvedModel, usage?.input_tokens ?? 0, usage?.output_tokens ?? 0);

  // Now process the response (extract text, etc.)
  const text = extractMessageText(apiResponse);
  // ... rest of success path

} catch (error) {
  // If we got a partial response (streaming errors, content filter after tokens consumed)
  // the usage variables are already set from above
  
  // Log the work with error status BUT include token costs
  await db.insert(agentWorkLog).values({
    userId,
    agentId,
    taskId,
    action: 'error',
    outputRef: null,
    durationMs: Date.now() - startTime,
    costUsd,  // Captured even on failure
    tokensUsed,
    details: JSON.stringify({
      error: error instanceof Error ? error.message : String(error),
      model: resolvedModel,
      tokensUsed,
      costUsd,
    }),
  });

  // Re-throw for BullMQ retry logic
  throw error;
}
```

3. **Also handle streaming errors** if using streaming API. The Anthropic SDK may throw mid-stream after some tokens are already consumed. In streaming mode, accumulate token counts from `message_delta` events.

4. **Add a `calculateCost` helper** if one doesn't exist:
```typescript
function calculateCost(model: string, inputTokens: number, outputTokens: number): number {
  // Approximate pricing per 1M tokens
  const pricing: Record<string, { input: number; output: number }> = {
    'claude-sonnet-4-20250514': { input: 3, output: 15 },
    'claude-opus-4-20250514': { input: 15, output: 75 },
  };
  const p = pricing[model] ?? pricing['claude-sonnet-4-20250514'];
  return (inputTokens * p.input + outputTokens * p.output) / 1_000_000;
}
```

5. **Update the cost aggregation query** (in agent routes or dashboard) to include error entries in total cost calculation — they should already if they query `agent_work_log` without filtering by action type.
