# FIX-003 — Raw SQL in Health Check

## Agent Instructions

Replace raw `pool.query()` with Drizzle ORM in the health check endpoint.

**Read:** `CRITICAL-FIXES.md` Section FIX-003, `src/server/index.ts` lines 62-72

**What to do:**

1. Replace `pool.query("SELECT tablename FROM ...")` with Drizzle:
```typescript
import { sql } from 'drizzle-orm';

app.get('/api/health', async (_req, res) => {
  try {
    const result = await db.execute(
      sql`SELECT tablename FROM pg_catalog.pg_tables WHERE schemaname = 'public'`
    );
    res.json({ status: 'ok', tables: result.rows.length });
  } catch (err) {
    res.status(503).json({ status: 'error', message: 'Database unreachable' });
  }
});
```

2. Even better — derive table count from the Drizzle schema instead of querying pg_catalog:
```typescript
import * as schema from '../db/schema';
const TABLE_COUNT = Object.keys(schema).filter(k => schema[k]?.constructor?.name === 'PgTable').length;

app.get('/api/health', async (_req, res) => {
  try {
    await db.execute(sql`SELECT 1`); // connectivity check
    res.json({ status: 'ok', tables: TABLE_COUNT });
  } catch {
    res.status(503).json({ status: 'error', message: 'Database unreachable' });
  }
});
```

3. Remove the `pool` import from `index.ts` if it's no longer used anywhere.
