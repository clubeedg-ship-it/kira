# FIX-010 — N+1 Query in Task Detail

## Agent Instructions

Optimize the task detail endpoint from 4-6 sequential queries down to 1 join + 2 parallel queries.

**Read:** `CRITICAL-FIXES.md` Section FIX-010, `src/server/index.ts` lines 242-280 (the `TaskDetailResponse` type and surrounding handler)

**What to do:**

1. **Find the task detail handler** — the endpoint that returns a task with hierarchy, dependencies, and work log. It's likely `GET /api/v1/tasks/:id` with `?detail=true` or a separate `/api/v1/tasks/:id/detail` endpoint.

2. **Replace sequential queries with a single JOIN for task + hierarchy:**

```typescript
const [result] = await db
  .select({
    // Task fields
    taskId: tasks.id,
    taskTitle: tasks.title,
    taskDescription: tasks.description,
    taskStatus: tasks.status,
    taskPriority: tasks.priority,
    taskExecutorType: tasks.executorType,
    taskExecutorId: tasks.executorId,
    taskRequiresInput: tasks.requiresInput,
    taskDueDate: tasks.dueDate,
    taskScheduledDate: tasks.scheduledDate,
    taskDuration: tasks.duration,
    taskContext: tasks.context,
    taskEnergy: tasks.energy,
    taskSource: tasks.source,
    taskTags: tasks.tags,
    // Hierarchy via LEFT JOINs
    milestoneId: milestones.id,
    milestoneTitle: milestones.title,
    projectId: projects.id,
    projectTitle: projects.title,
    areaId: areas.id,
    areaName: areas.name,
    objectiveId: objectives.id,
    objectiveTitle: objectives.title,
  })
  .from(tasks)
  .leftJoin(milestones, and(eq(milestones.id, tasks.milestoneId), eq(milestones.userId, userId)))
  .leftJoin(projects, and(eq(projects.id, tasks.projectId), eq(projects.userId, userId)))
  .leftJoin(areas, and(eq(areas.id, projects.areaId), eq(areas.userId, userId)))
  .leftJoin(objectives, and(eq(objectives.id, projects.objectiveId), eq(objectives.userId, userId)))
  .where(and(eq(tasks.id, taskId), eq(tasks.userId, userId)))
  .limit(1);
```

3. **Parallelize the remaining queries:**

```typescript
const [depsResult, workLogResult] = await Promise.all([
  // Dependencies: blocked_by + blocks in one query
  db.select({
    direction: sql<string>`CASE WHEN ${dependencies.blockedId} = ${taskId} THEN 'blocked_by' ELSE 'blocks' END`,
    depTaskId: tasks.id,
    depTaskTitle: tasks.title,
    depTaskStatus: tasks.status,
  })
  .from(dependencies)
  .innerJoin(tasks, and(
    sql`${tasks.id} = CASE 
      WHEN ${dependencies.blockedId} = ${taskId} THEN ${dependencies.blockerId}
      ELSE ${dependencies.blockedId}
    END`,
    eq(tasks.userId, userId)
  ))
  .where(and(
    eq(dependencies.userId, userId),
    sql`(${dependencies.blockedId} = ${taskId} OR ${dependencies.blockerId} = ${taskId})`,
  )),

  // Work log
  db.select()
    .from(agentWorkLog)
    .where(and(eq(agentWorkLog.userId, userId), eq(agentWorkLog.taskId, taskId)))
    .orderBy(desc(agentWorkLog.createdAt))
    .limit(20),
]);
```

4. **Reshape the flat join result** into the nested `TaskDetailResponse` format:
