# FIX-001 — Extract Inline Routes to Router (Auth Bypass)

## Agent Instructions

You are fixing a **CRITICAL SECURITY VULNERABILITY**: four large route handlers defined inline in `src/server/index.ts` (lines ~408-1012) bypass the auth middleware because they're not registered through the router architecture.

**Read these files first:**
1. `CRITICAL-FIXES.md` — Section FIX-001 for full context
2. `AGENTS.md` — project conventions
3. `src/server/index.ts` — the file with inline routes (1444 lines)
4. `src/server/routes/index.ts` — the router that HAS auth middleware
5. `src/server/middleware/auth.ts` — the auth middleware
6. `src/server/routes/tasks.ts` — example of correctly structured route file

**The problem:**
`src/server/index.ts` has route handlers defined directly on the `app` object (~lines 408-1012) instead of using the `router` in `src/server/routes/`. The auth middleware is applied to the router, not to `app` — so these inline handlers have NO authentication. Any unauthenticated request can access them.

**What to do:**

1. **Identify** all inline `app.get()`, `app.post()`, `app.put()`, `app.patch()`, `app.delete()` handlers in `index.ts` that are NOT `/api/health` or `/api/v1/auth/*`
2. **For each handler**, determine which route file it belongs to (tasks, projects, areas, etc.)
3. **Move** the handler into the appropriate `src/server/routes/*.ts` file, converting `app.get(...)` to `router.get(...)`
4. **Ensure** every handler uses `req.userId` (which auth middleware provides)
5. **Remove** the inline handlers from `index.ts`
6. **Verify** `index.ts` only contains: imports, middleware setup, auth handler, health check, router mount, error handler, server start
7. **Test** that unauthenticated requests to moved routes return 401

**Target state for `index.ts`:**
```typescript
// ~100 lines max:
// imports
// middleware (cors, json, etc.)
// auth routes (Better-Auth handler)
// health check
// app.use('/api/v1', authMiddleware, router)  // ALL /api/v1 routes go through auth
// error handler
// server.listen()
```

**Rules:**
- Do NOT change any route logic — just move it
- Do NOT change any query logic — just relocate
- Preserve all response formats exactly
- If a handler references local helper functions in `index.ts`, move those too (or to a shared utils file)
- Run `npm test` after changes
