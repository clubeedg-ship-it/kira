# FIX-004 — Worker Crash Recovery

## Agent Instructions

Fix unhandled promise rejections in the BullMQ worker that cause silent death of all job processing.

**Read:** `CRITICAL-FIXES.md` Section FIX-004, `src/server/worker.ts` (75 lines), `src/server/jobs/agent-work.ts`

**What to do:**

1. **Add process-level error handlers** at the top of `worker.ts`:
```typescript
process.on('unhandledRejection', (reason, promise) => {
  console.error('[worker] Unhandled rejection:', reason);
  // Don't crash — log and continue
});

process.on('uncaughtException', (err) => {
  console.error('[worker] Uncaught exception:', err);
  // For truly fatal errors, do graceful shutdown
  shutdown().then(() => process.exit(1));
});
```

2. **Add per-worker error handlers** after worker creation:
```typescript
agentWorkWorker.on('error', (err) => {
  console.error(`[worker:agent-work] Worker error:`, err.message);
});

agentWorkWorker.on('failed', (job, err) => {
  console.error(`[worker:agent-work] Job ${job?.id} failed:`, err.message);
});

agentWorkWorker.on('stalled', (jobId) => {
  console.warn(`[worker:agent-work] Job ${jobId} stalled — will be retried`);
});

// Same for heartbeatWorker
```

3. **Add Redis connection resilience** — configure BullMQ connection with retry:
```typescript
const connection = createRedisConnection();
// Ensure the Redis connection config includes:
// maxRetriesPerRequest: null (BullMQ requirement for workers)
// enableReadyCheck: false
// retryStrategy: (times) => Math.min(times * 500, 30000)
```

4. **Add a health check** for the worker process (optional but recommended):
```typescript
import http from 'http';

const healthServer = http.createServer((req, res) => {
  if (req.url === '/health') {
    res.writeHead(200);
    res.end(JSON.stringify({
      status: 'ok',
      workers: {
        agentWork: agentWorkWorker.isRunning(),
        heartbeat: heartbeatWorker.isRunning(),
      }
    }));
  } else {
    res.writeHead(404);
    res.end();
  }
});
healthServer.listen(3009); // Worker health on different port
```

5. **Add job retry configuration** in the queue setup (wherever jobs are enqueued):
```typescript
// In agent-work job enqueue:
await queue.add('agent-work', payload, {
  attempts: 3,
  backoff: { type: 'exponential', delay: 5000 },
  removeOnComplete: 100,
  removeOnFail: 500,
});
```
