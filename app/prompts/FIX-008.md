# FIX-008 — S3 Local Fallback Path Traversal

## Agent Instructions

Fix a **CRITICAL SECURITY VULNERABILITY**: the local S3 fallback allows path traversal via `../` in storage keys, enabling arbitrary file read/write on the server.

**Read:** `CRITICAL-FIXES.md` Section FIX-008, `src/server/lib/s3.ts` (158 lines, focus on lines 110-130)

**What to do:**

1. **Create a path validation utility** at the top of `s3.ts`:
```typescript
const SAFE_PATH_SEGMENT = /^[a-zA-Z0-9._-]+$/;

function validateStorageKey(key: string): void {
  const segments = key.split('/').filter(Boolean);
  for (const segment of segments) {
    if (segment === '.' || segment === '..') {
      throw new Error(`Path traversal attempt blocked: ${key}`);
    }
    if (!SAFE_PATH_SEGMENT.test(segment)) {
      throw new Error(`Invalid path segment in storage key: "${segment}"`);
    }
  }
}

function safeLocalPath(baseDir: string, key: string): string {
  validateStorageKey(key);
  const resolved = path.resolve(baseDir, ...key.split('/').filter(Boolean));
  const resolvedBase = path.resolve(baseDir);
  if (!resolved.startsWith(resolvedBase + path.sep) && resolved !== resolvedBase) {
    throw new Error(`Path traversal attempt blocked: resolved "${resolved}" is outside "${resolvedBase}"`);
  }
  return resolved;
}
```

2. **Apply `safeLocalPath` everywhere** the local fallback constructs file paths:

In `uploadFile`:
```typescript
const localPath = safeLocalPath(LOCAL_FALLBACK_DIR, key);
```

In `getFileUrl` / `downloadFile` / any other function that reads from local storage:
```typescript
const localPath = safeLocalPath(LOCAL_FALLBACK_DIR, key);
```

3. **Also validate keys before S3 operations** (defense in depth — even for real S3, malicious keys shouldn't be allowed):
```typescript
export async function uploadFile(key: string, body: ..., contentType = '...') {
  validateStorageKey(key);  // Validate regardless of S3 vs local
  await ensureS3Bucket();
  // ... rest
}
```

4. **Audit key construction** — find everywhere a storage key is built and ensure user input is sanitized:
```bash
grep -rn "uploadFile\|getFileUrl\|downloadFile" src/server/ --include="*.ts"
```
Keys should be built from UUIDs and known constants only. If any user-controlled string flows into a key, validate or sanitize it.
