## CRITICAL CONSTRAINT: CORE BUSINESS DILUTION

**Problem:** 20yo founder + small team cannot run AI consultancy + fintech + energy platform simultaneously.

**Solution: Paperclip + Kira Sequential Execution Model**
- **Paperclip** (github.com/paperclipai/paperclip) for autonomous background project execution
- **Kira** for predigested inbox of scheduled tasks, sequential priority execution
- UI inspiration: Clawport (clawport.dev), Mission Control (builderz-labs/mission-control)
- **Each portfolio project = background entity** (including distribution growth strategy)
- Daily review of background projects until it's time to focus
- Focus shifts only when all requirements are met
