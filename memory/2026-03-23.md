Otto initiated a complete redesign of Kira from scratch. Codename: **Nuke**.

### 11 Concepts Approved & Documented in ~/nuke/

1. **ARCHITECTURE.md** — 7-layer stack: NemoClaw (security) → MetaClaw (evolution) → Paperclip (orchestration) → GSD+Fleet+Triage (execution) → MemOS (memory) → VDR (documents) → NemoClaw+Discord+Notion+NativeUI (interface)
2. **MEMORY.md** — "Agents think, they don't journal." MemOS auto recall/save. Scribe agent extracts from transcripts. No agent does its own housekeeping. Context hygiene: 97.5% of context for thinking, not logging.
3. **ORCHESTRATION.md** — 9 separate Paperclip companies (IAM, OttoGen, CuttingEdge, Abura, Omiximo, ZenithCred, SentinAgro, Chimera, Oopuo Holding). Each gets dedicated agent. Full isolation — no shared context, no budget mixing.
4. **TRIAGE.md** — Omi (phone mic, no hardware) for physical capture. 7-stage triage pipeline. Call detection via iOS CallKit. Native SwiftUI app for iOS+macOS. Omi is MIT licensed (forkable/resellable).
5. **AGENTS.md** — 4 core (Kira, Scribe, Sentinel, Dispatcher) + 8 company agents (Aria, Rex, Marco, Luna, Nexus, Vega, Scout, Cipher). Extensible: Otto creates new agents on-demand with full isolation from day one.
6. **NOTION-SYNC.md** — Notion IS the UI. Paperclip invisible. Bidirectional sync. Otto works entirely in Notion, sees everything there.
7. **DISCORD.md** — One bot per agent (separate Discord presence, avatar, status). Auto-threading per task. Agent status = Discord presence (online/idle/DND).
8. **OAUTH-RELAY.md** — Proxy for subscription-based auth (Claude Max, ChatGPT Plus). Routes by model prefix. Avoids per-token API costs.
9. **MIGRATION.md** — Phase 0: install build tools on v1 NOW. Phase 1: build Nuke from clean foundation. Phase 2: cutover after proven. No half-measures on v1.
10. **BUILD-ORDER.md** — Phase 0 (this week): GSD, OAuth relay, MetaClaw, MemOS. Everything else waits for Nuke clean build.
11. **A2A.md** — Google Agent2Agent protocol for agent communication. Agent Cards, sync/stream/async. All traffic mirrored to Discord.
